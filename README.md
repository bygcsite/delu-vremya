# Делу время

Простой список задач на HTML, CSS и JavaScript — без сборки, зависимостей и сервера приложений.

Сайт: [todo.bygc.site](http://todo.bygc.site)

## Возможности

- Добавление, выполнение и удаление задач.
- Создание проектов и перенос задач через меню «⋯».
- Завершение проектов, архив и возврат в работу.
- Удаление проекта с выбором: сохранить задачи или удалить вместе с проектом.
- Фильтры «Все», «В работе», «Готово».
- Сохранение в localStorage и обновление списка в соседних вкладках.
- Адаптивный интерфейс и управление с клавиатуры.

## Запуск

Из папки проекта запустите статический HTTP-сервер:

```sh
python3 -m http.server 8080
```

Откройте [localhost:8080](http://localhost:8080).

Для публикации загрузите `index.html`, `styles.css`, `app.js` и `favicon.svg` в корневую папку отдельного сайта. PHP и база данных не нужны.

## Структура

- `index.html` — разметка, формы и диалоги.
- `styles.css` — палитра, оформление и мобильная версия.
- `app.js` — задачи, проекты, фильтры и сохранение.
- `favicon.svg` — значок сайта.

## Хранение данных

Данные сохраняются только в браузере на текущем адресе сайта. Авторизации и синхронизации между устройствами нет. Очистка данных браузера удаляет список. HTTP и HTTPS используют разные хранилища. При одновременных изменениях в нескольких вкладках применяется последнее сохранение.

## Проверки

Проверены добавление, выполнение, фильтры, перенос, архивирование и восстановление проектов, оба варианта удаления проекта, обработка недоступного и повреждённого хранилища. HTML из пользовательского ввода вставляется как текст через `textContent`.

В браузере проверена вёрстка на ширинах 390 и 320 px: длинное название задачи, меню действий, окно переноса, архив, возврат и окно подтверждения удаления. Это проверка размеров окна, не физического телефона.

## Использование AI

Использован OpenAI Codex: подготовка интерфейса, реализация логики, проверка кода и тестирование в браузере. В приложении нет AI API и сторонних библиотек.
